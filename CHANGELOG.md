# Statholme

## 0.2.0

- Bars on extra chat windows are now saved account-wide by window name, so a window called Guild has the same bars on every character. Your existing window settings carry over the first time each window shows up.
- Chattynator support: with Chattynator running, the chat bars sit on its windows instead of Blizzard's, and the bar on the input's side covers it until you start typing.

## 0.1.0

- First release: small bars on the minimap, the chat windows and the micro menu, showing the time, FPS, ping, friends, guild, mail, bags, durability, gold, location, spec, memory and item level.
- Hover any readout for details, click it to open the matching Blizzard window, and Shift+right-click a slot to change what it shows.
- `/statholme` or `/sth` opens the settings.
